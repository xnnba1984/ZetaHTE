zeta_methods {ZetaHTE}R Documentation

Print and Summarize ZETA Results

Description

Compact displays of the global test, channel evidence, and descriptive summaries. Summary objects omit subject-level data and bootstrap matrices.

Usage

## S3 method for class 'zeta_test'
print(x, digits = 4L, ...)
## S3 method for class 'zeta_test'
summary(object, ...)
## S3 method for class 'summary.zeta_test'
print(x, digits = 4L, ...)
## S3 method for class 'zeta_interpretation'
print(x, digits = 4L, ...)

Arguments

x, object

The corresponding ZETA result object.

digits

Number of significant digits in printed numbers.

...

Reserved for compatibility with the standard generic functions.

Value

Print methods return their argument invisibly. The summary method returns a compact object including parameters and diagnostic tables.
