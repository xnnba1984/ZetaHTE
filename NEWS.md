# ZetaHTE 0.1.0

- First public release of the ZETA test for continuous and binary outcomes.
- Combine Jump, Tail linear, and Tail step scan channels using a residual
  wild bootstrap and a global test.
- Provide exploratory channel results, descriptive effect summaries, and
  optional user-specified positive-tail cutoffs.
- Include input checks, random-number state handling, and explicit reasons
  for unavailable results.
- Include base-R plots, three synthetic-data tutorials, native R help,
  offline HTML documentation, and automated tests.
